# 英语学习台 · 新人版

给刚毕业、英语偏弱的外企新人用的中文带学站点。纯静态网页，不用安装依赖，进度只存在当前浏览器。

线上：https://dpmoehre.github.io/learn-english/

任务进度看 [`todo.md`](todo.md) 与 [`docs/`](docs/) 施工牌。需求原文看 [`_Doc/001_需求整理/需求记录.md`](_Doc/001_需求整理/需求记录.md)。Agent 规则看 [`CLAUDE.md`](CLAUDE.md)。

## 能练什么

- 7 节新人课：情景、跟读、选择题、开口示范。
- 外企词典：缩写和职场词，用中文讲明白，可听词。
- 主题单词表：听单词 / 听例句，标掌握或待复习。
- 句卡、邮件模板、口语计时、测验。
- 学习统计：时间、数量、质量、整体考核。数字来自当前浏览器的真实记录，可导出备份，不跨设备同步。

不提供账号、云同步、录音打分、自动翻译或网页里的 AI 对话。口语陪练在 Cursor 对话里做。

## 使用

打开 `index.html`，或在本目录运行：

```
python3 -m http.server 8765
```

浏览器访问 http://127.0.0.1:8765 。手机请用线上地址，打开后如看到旧页就下拉刷新。

跟读：平板和电脑默认系统朗读；iPhone 默认网络发音。没声音时，在新人课里切换「系统朗读」或「网络发音」，并调大音量。

## 发布

GitHub Pages 读 `main` 分支根目录。改完跟读或统计后推到 `origin/main`，几分钟后线上生效。
