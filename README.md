# 英语学习台 · 新人版

为刚毕业、英语基础较弱的学习者设计。纯静态网页，不需要安装依赖。

- 7 节新人课程：中文情境与职场知识、21 句中英对照、慢速朗读、情景选择题与解析、口语示范。
- 可搜索外企常用词典，包含 HR、FYI、1:1 等 12 项。
- 保留句卡、邮件模板、口语计时和测验；修复原场景朗读按钮与选择高亮。
- 工具记录按本地日期刷新；课程完成记录跨天保留。存储不可用时仍可学习。
- 浏览器语音合成负责朗读，声音可用性取决于浏览器和系统。不提供录音、语音评分、自动翻译或 AI 对话。

## 使用

打开 index.html，或在此目录运行 `python3 -m http.server 8765`，浏览 http://localhost:8765 。

## 更新原 GitHub Pages

将 index.html、beginner.js、experience.js、experience.css、manifest.json 放在 dpmoehre/learn-english 仓库原网站目录，保持 beginner.js 与 index.html 同级。GitHub Pages 从 main 分支根目录自动发布。

## 验证

JavaScript 语法检查通过；浏览器已验证课程答题解析、完成记录、课程切换和词典搜索。

## 导航、交互与统计

五个独立导航区域；课程支持前后切换和继续学习；句卡支持掌握自评和待复习筛选。统计包括课程完成度、累计与连续学习天数、最近七天记录、首次答对率、错题回练。数据只保存在浏览器。旧版课程记录保留，但不推测旧版学习日期。

浏览器验证：导航切换、首次答错进入错题列表、回练跳转、答对后移出错题列表，同时首次答对率保持不变。
