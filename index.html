一张图记住全部骨架

提出工作请求时，可以参考这四块：礼貌开头 + 把事情说清楚 + 明确动作 + 给出截止时间。

PoliteCould you / I hope you’re well
ClearI’m writing about the Q3 report
Actionplease review / confirm / send
Deadlineby Friday 5pm / before the meeting
套一句就能用

Could you please send the latest version by Friday 5pm so that we can prepare for Monday’s meeting?

把下划线三处换成你的内容，就是一封能发的邮件核心句。
